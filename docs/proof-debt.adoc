stated in the proof ledger's trust-boundary column.

  the template's own headings)
  ** *Owner*: @hyperpolymath
  ** *Plan*: once templates are typed (work package 1, milestone 2), certify
     the rendered page rather than the content tree, so the template's
     structure is inside the witness.
  ** *Deadline*: INDEFINITE: dependent on work package 1, milestone 2.

* `Attest.idr` / `Ddraig.idr` — raw HTML blocks are not inspected
  ** *Owner*: @hyperpolymath
  ** *Plan*: replace the hero/card/badge uses of raw HTML with typed
     constructs (shortcodes, work package 1, milestone 4), after which raw
     blocks can be refused by the certifier. Until then they are counted per
     page in the attestation file.
  ** *Deadline*: INDEFINITE: dependent on work package 1, milestone 4.

* `Html.idr` — tag and attribute names are escaped but not validated
  ** *Owner*: @hyperpolymath
  ** *Plan*: index `Elem` and `Void` by a closed type of HTML element names.
  ** *Deadline*: INDEFINITE: not scheduled.

  ** *Owner*: @hyperpolymath
  ** *Plan*: restructure `collectKeys` to recurse on a structurally smaller
     list, then drop the `covering` annotations.
